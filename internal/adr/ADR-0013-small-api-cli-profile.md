# ADR0013 — Experimental protected Small API scaffold

Date: 2026-10-29. Accepted for the user-authorized Small API profile continuation of existing #20. #3 remains Blocked; full #20/#11 qualification, original dependencies, W5 milestone, estimates and M0 remain unchanged.

Extend the source-only CLI with `new --profile small-api` and `validate --profile small-api --config <file>`. Keep the portable-request-reply default and behavior. Bundle the template in Tooling so generation requires an Engine checkout but no Samples checkout, network, compiler, shell, installation or service. Retain deterministic fixed files, observed source hashes, trusted parents, no overwrite, owned staging cleanup, source-path safeguards and name-independent namespace/assembly identity from ADR0012.

The generated Web SDK consumer uses unchanged Core, Composition, Identity/Tenancy, HTTP/GraphQL adapters and actual Roslyn-generated typed/lazy gateways. Compile the complete immutable plan and reject unsupported Worker/provider selections before host construction. Default API-only disables GraphQL registration and mapping. Deliver API+GraphQL, GraphQL-only and all-off configurations. All-off constructs no host/store/listener and reads no TLS/signing-key files. Package presence does not prove activation.

Protected calls require actual RS256 JWT validation (signature/issuer/audience/lifetime/type/unambiguous claims), then fresh identity/membership/resource/policy resolution through TenantOperationDispatcher and checked data access. User-provided tenant/subject/role headers are metadata only. Alice/tenant-a and Bob/tenant-b membership and the in-memory catalog are declared local fixtures, not a real IdP, provider/RLS or production authority. The same generated gateways and business handlers serve HTTP and optional GraphQL.

Provide explicit `--self-test` for ephemeral localhost HTTPS fixtures and a separate `--serve` path requiring caller-provided TLS PFX/public RSA PEM/configuration plus a fresh readiness report. No implicit self-signed or token-issuing normal server mode; do not write keys/tokens to readiness/logs. Serving binds loopback only. Existing custom-CA/hostname validation, JWT hardening and GraphQL POST-only/schema/IDE/WS/batching/multipart/incremental restrictions carry over from ADR0008. Lifecycle cleanup must close listeners and balance owned handlers.

The self-test must consume the actual generated configuration files and send real HTTPS requests; Samples must invoke the real CLI, restore/build/run the fresh generated project, inspect emitted registrations/runtime graph and verify cross-tenant denial with zero business work. Test API-only, API+GraphQL, GraphQL-only, all-off and invalid/unsupported configurations, hostile metadata, token failures, fresh revocation/owner/policy checks, cancellation and disabled module counters. A scaffold build or record of module names alone is insufficient.

This is correctness scaffolding, with no startup, throughput or size claim. Timing benchmarks are Not required for this bounded slice; original full #20 tooling benchmark and Small API performance/reference gates remain open. No full transport-schema generation, package/global-tool distribution, NativeAOT, production, cloud or provider acceptance follows. See the [predeclared protocol](../validation/small-api-cli-protocol.md).
