## Correctness matrix

- Identity: exact issuer/subject pair, case sensitivity, bounded immutable values/trust allowlists, empty trust deny, malformed UTF16/control/bounds and exact validity boundaries. Snapshot construction is not authentication.
- Invocation: valid A/A and B/B; same resource ID in both tenants; all selected/member/resource tenant mismatches; wrong principal issuer/subject, wrong resource kind/ID/action; default policy deny; metadata/admin/wildcard spoof cannot grant membership.
- Lifetime: fresh identity/membership/resource/policy per call, revocation on next call, injected UTC and monotonic-clock expiry/not-before/lease expiry before factory and inside handler, permanent revocation after observed invalidity despite clock recovery, retained context after success/error/cancel, replay/cross-operation scope attempts.
- Isolation: mutable input changed while authority sources await, with trusted deep snapshot; parallel A/B calls without ambient state; pre-dispatch authorization denials have zero business factory/constructor/read/write, though authority lookups/stateless gateway work may occur. Later cancellation/expiry must clean already created handlers rather than claim they were never created.
- Failure: caller cancellation at each boundary, source/policy faults, null/malformed/misbound outputs, handler and cleanup failures, immutable registries/context and lazy registration.
- Integration: tenant dispatcher actually delegates through existing Core ownership/dispatch; a generated Core gateway consumer reaches a tenant-aware handler using checked scope. Runtime has no Roslyn/provider/host dependencies. Existing Core/Composition/codegen suites remain green.
