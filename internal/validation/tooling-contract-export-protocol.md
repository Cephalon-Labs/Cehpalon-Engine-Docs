Do not mistake structural validation for custom validators. At least one schema-valid/domain-invalid request must be rejected at runtime.

- Actual HTTPS operations and response JSON must agree with exported contracts; cross-tenant denials, disabled-module behavior, auth and forbidden introspection/schema endpoints still pass after export. Reuse the complete generated Small API39case/self-test and caller-configured serving proof, plus full portable70check regression and Engine contracts on both hosts.
- Invalid/unsupported config rejects before any output/schema work. Existing empty/nonempty directory/file, observed symlink/dangling target and known checkout targets are preserved. Test publication failure with truthful lifecycle counters and no overwritten outsider bytes. Clean only owned expected staging, retain unknown content, document trusted-parent/race limits.
- Capture exact source hashes, emitted schemas/registry, commands, stdout/stderr/timeouts and public counters. Private keys/PFX/passwords/tokens, compiled artifacts, source clone objects and private fixture directories stay excluded from committed raw evidence. Verify raw bytes against Git blobs without newline normalization.

Every required bounded check must pass. A source fix requires relevant complete matrix verification; retain failed attempts and never replace unfavorable cases. Full schema universality, runtime transport/provider acceptance and production maturity are separate.
