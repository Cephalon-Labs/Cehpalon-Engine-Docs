# Experimental tooling measurements

The source-checkout CLI and operation generator have a fixed, observational benchmark in [Samples tooling-benchmark](https://github.com/Cephalon-Labs/Cehpalon-Engine-Samples/tree/main/tooling-benchmark). Build with the exact SDK and Engine revision in its lock file, then run `tools/benchmark_tooling.py` with a fresh `.local` output directory. Run owned measurements sequentially on a shared host.

The generator comparison actually emits assemblies for 1, 3 and 32 operations. Fresh compiler graphs, retained no-op inputs and one-operation-ID edits are separate cases. The generated path times generator execution plus emit; the manual path times emit of an independently authored equivalent typed registry. Parsing, reference loading and manual authoring are outside both clocks. Both paths check registration structure and actual lazy factory, dispatch and disposal behavior. This comparison does not measure developer productivity, full SDK builds or runtime request latency.

CLI observations cover portable/Small API scaffolding, pure validation and API-only/combined/GraphQL-only/all-off contract exports. Every invocation is a fresh process and every generated output is verified. Primers, build preparation and output checking prime filesystem caches; these are not cold-disk costs. Enabled GraphQL export constructs and disposes its actual schema provider. Disabled modules do none of that work, and export opens no host or listener and invokes no business handler or tenant authority.

All raw rows, primers and failed attempts are retained. Correctness and completeness require the whole declared matrix. Timing summaries use the declared sample CV and nearest-rank percentiles without filtering. CV above 15% flags unstable inference. There is no numerical performance acceptance or framework speedup claim. CPU quantization and process-wide allocation noise are retained; CLI child CPU is unavailable and reported as null.

Windows and WSL observations record their actual SDK/runtime and storage paths. A native WSL SDK with mounted source/output differs from Windows NTFS; cross-host ratios do not establish an OS speedup. Shared-host resources are not a reference machine. Full #20 Test/Benchmark remains Planned, runtime maturity M0 and #3 Blocked. Provider, production, distribution, AOT/trimming and IDE qualification remain separate.
